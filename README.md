# ORBIT

> **Navigate the Market.**

ORBIT는 여러 거래소의 API를 연결해 자동매매 전략을 운영하고, 주문·포지션·리스크를 한 화면에서 관리하는 트레이딩 플랫폼입니다.

복잡한 매매 시스템을 누구나 이해할 수 있게, 중요한 정보와 제어 기능을 명확하고 간단하게 제공합니다.

## What ORBIT does

- 여러 거래소 계정과 API Key 연결
- 조건 기반 자동매매 전략 설정 및 실행
- 실시간 주문·체결·포지션 상태 확인
- 손익, 리스크 이벤트, 시스템 로그 통합 조회
- Worker별 실행 상태 및 긴급 중지 제어
- 반응형 웹 대시보드 제공

## Dashboard

ORBIT는 우주 관제센터에서 영감을 받은 차분하고 정교한 시각 디자인을 사용합니다.  
다만 기능 명칭은 누구나 이해할 수 있는 표준 금융 용어를 유지합니다.

| 화면 | 제공 정보 |
|---|---|
| 대시보드 | 전체 자산, 손익, 활성 포지션, 실행 상태 |
| 거래소 연결 | 거래소 계정 및 API Key 관리 |
| 전략 | 진입·청산 조건, 레버리지, 리스크 한도 설정 |
| 포지션 | 현재 보유 포지션, ROE, TP/SL, 청산 정보 |
| 주문 내역 | 주문 요청·체결·취소·거절 이력 |
| 로그 | 신호, 주문, 오류, 리스크 이벤트를 시간순으로 확인 |
| 리스크 관리 | 손실 한도, 쿨다운, 긴급 중지, 수동 청산 |

## Safety First

ORBIT는 실거래보다 안전한 운영을 우선합니다.

- API Key는 거래 권한만 사용하며 출금 권한을 허용하지 않습니다.
- 민감한 키와 운영 비밀값은 저장소에 포함하지 않습니다.
- 중복 주문 방지, 거래소 상태 동기화, 손실 제한, 긴급 중지 기능을 제공합니다.
- 실거래 전에는 Paper Trading과 충분한 검증을 권장합니다.

> ORBIT는 투자 조언이나 수익을 보장하지 않습니다. 모든 거래 판단과 책임은 사용자에게 있습니다.

## Development

현재 멀티 거래소 자동매매 플랫폼을 구축 중입니다.

- Frontend: React, TypeScript
- Backend: Spring Boot
- Database: PostgreSQL
- Cache & Queue: Redis
- Runtime: Docker
- CI/CD: GitHub Actions

개발·보안·운영 구조는 [플랫폼 구축 문서](docs/platform-build.md)에서 확인할 수 있습니다.
